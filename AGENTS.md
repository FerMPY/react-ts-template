# AGENTS.md

React 19 + TanStack Start app that builds either as an SSR server (Nitro) or a static SPA.
Package manager: pnpm. Node 24.

## Commands

- `pnpm dev`: dev server with SSR on http://localhost:3000 (`pnpm dev:spa` for SPA mode)
- `pnpm check`: format check + lint (type-aware, warnings fail) + typecheck. Run before finishing.
- `pnpm test`: Vitest. `pnpm test:watch` for watch mode.
- `pnpm lint:fix` / `pnpm format`: auto-fix lint issues / format everything
- `pnpm lint:react`: React Doctor scan (React anti-patterns, a11y, security)
- `pnpm build` / `pnpm build:spa`: SSR build (`.output/`) / static SPA build (`dist/client/`)

## Conventions

- Import app code through the `#/` alias (`#/components/...`), which maps to `src/`.
- Routes are files in `src/routes/` (TanStack Router file routing). `src/routeTree.gen.ts` is
  generated by the dev server and build; never edit it by hand.
- Data loading: define `queryOptions` in `src/queries/`, call `queryClient.query(options)` in
  the route `loader`, and read it with `useSuspenseQuery(options)` in the component.
  `ensureQueryData`/`fetchQuery`/`prefetchQuery` are deprecated.
- The React Compiler is on: don't add `useMemo`, `useCallback` or `memo` for performance.
- Code must work in both modes. Server functions and server routes only work in the SSR
  build; in the SPA build everything runs in the browser.

## UI

- Use the shadcn/ui components in `src/components/ui/` (Base UI primitives). Add new ones
  with `pnpm dlx shadcn@latest add <component>`, then run `pnpm format`.
- `@shadcn/lint` enforces the design system: components own their colors, spacing and
  typography (only layout classes like `mt-4`, `w-full` may be passed), colors must be theme
  tokens (`bg-primary`, `text-muted-foreground`), and arbitrary values are off-limits. The
  error messages say which variant, size or token to use instead; follow them rather than
  disabling the rule. Theme tokens live in `src/styles.css`.
- Use `cn()` from `#/lib/utils` to merge classes.

## Tests

- Test files live next to the code as `*.test.tsx`. Globals (`describe`, `it`, `expect`) are on.
- Use `renderWithRouter` from `#/test/render-with-router` for anything that renders a
  `<Link>` or uses router hooks; pass `{ withQueryClient: true }` for TanStack Query.
